**# ReadTree｜文献阅读树

**一个用于系统阅读学术文献、建立研究知识体系的开放式框架。**

ReadTree希望解决一个常见问题：研究者阅读了大量论文，却很难持续整理不同研究之间的联系。

ReadTree以研究问题为中心，将论文的理论基础、识别策略、实证证据和研究分歧组织成可以不断扩展的文献知识树。

## 核心原则

- **以研究问题组织文献：** 不仅按照学科和关键词分类，还要明确每篇论文回答什么问题。
- **建立文献联系：** 记录理论基础、方法改进、证据补充与研究分歧。
- **核验研究证据：** 优先根据期刊原文、工作论文和作者资料核对研究设计与结论。
- **避免重复收录：** 识别已阅读论文及工作论文、正式发表版本之间的关系。
- **支持长期积累：** 通过持续阅读建立可以检索、更新和扩展的知识体系。

## 当前版本

**ReadTree v0.1｜框架设计阶段**

目前主要提供文献分类、阅读流程与知识树设计方案。自动检索、持久化去重和交互式知识树尚未实现。

欢迎研究者提出建议，共同完善这一开放式科研阅读框架。
